# LUCCI Drive Output OAuth

This repository hosts the public OAuth support pages for **LUCCI Trader's Edge**.

LUCCI is a private personal trading intelligence system designed to organize learning materials, preserve evidence, and support Gio's approved trading process.

This site exists only to provide public information required for Google's OAuth application configuration.

## Privacy

LUCCI respects user-controlled data ownership.

The application:

- does not sell personal data;
- does not publish private trading materials;
- does not store course recordings publicly;
- does not commit credentials, tokens, or private documents to GitHub;
- uses Google OAuth permissions only for functionality explicitly authorized by the user.

## Data Access

LUCCI uses Google Drive access only for application-generated output files.

Requested OAuth permission:

`https://www.googleapis.com/auth/drive.file`

This permission limits access to files created or explicitly shared with the application.

## Security

LUCCI follows:

- least-privilege access;
- revocable OAuth authorization;
- separation between source materials and derived outputs;
- private handling of generated artifacts.
